# Water Operation KM Dashboard
## ระบบจัดการองค์ความรู้งานสูบส่งและสูบจ่ายน้ำ

โปรเจกต์นี้อยู่ในขั้นตอน **รวบรวมและจัดโครงสร้างข้อมูล** — ยังไม่เริ่มสร้าง Dashboard จนกว่าจะได้รับคำสั่ง "เริ่มสร้าง Dashboard"

## เป้าหมาย

1. ถ่ายทอดความรู้ให้พนักงานใหม่
2. นำเสนอผู้บริหาร
3. เก็บเป็นฐานข้อมูลองค์ความรู้ส่วนตัว
4. แสดงศักยภาพการใช้ AI ช่วยทำให้งานซับซ้อนเข้าใจง่ายขึ้น

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `data/master-data.json` | Master Data สะสมทั้งหมด (อัปเดตทุกครั้งที่ได้รับข้อมูลชุดใหม่) |

## Master Data หลัก

**ระบบสูบส่งหลัก 4 รายการ:** MH มหาสวัสดิ์, TR1 บางเขน, TR2 บางเขน, TR3 บางเขน

**สถานีสูบจ่ายน้ำ 10 แห่ง:** SR สำโรง, KT คลองเตย, BP บางพลี, LK ลาดกระบัง, MB มีนบุรี, LP ลุมพินี, LA ลาดพร้าว, TP ท่าพระ, RB ราษฎร์บูรณะ, PK เพชรเกษม

## กติกาการจัดการข้อมูล

- รับข้อมูลทีละชุด แล้วจัดเข้าโครงสร้างใน `master-data.json`
- ข้อมูลที่ยังไม่ได้รับ ใส่ค่า "ยังไม่มีข้อมูล" — ห้ามเดาข้อมูลจริง
- Sample Data ต้องระบุแยกให้ชัดเจน
- ข้อมูลซ้ำให้ Merge เป็นชุดเดียว / ข้อมูลขัดแย้งให้แจ้งและรอยืนยัน

## เมนู Dashboard ที่วางแผนไว้

Overview · System Map · Main Transmission · Pumping Stations · Flow & Pressure Analytics · RTU Monitoring · Shift Handover · KM Library · Data Upload

**Tech Stack (เมื่อเริ่มสร้าง):** React + Tailwind CSS + Recharts + Lucide React
