# TOEIC Quest: Conquer 990

เกมฝึก TOEIC สไตล์ RPG บน Google Apps Script + Google Sheets
ที่ช่วยให้ผู้เรียนฝึกคำศัพท์ ไวยากรณ์ และการอ่านภาษาอังกฤษเชิงธุรกิจ
ได้อย่างสนุก พร้อมระบบเก็บคะแนน เลเวล เหรียญ เหรียญตรา และกระดานผู้นำ

---

## 1. โปรเจกต์นี้คืออะไร

**TOEIC Quest: Conquer 990** คือเว็บแอปฝึก TOEIC ในรูปแบบเกม Quest
ผู้เล่นสามารถ:

- กรอกชื่อผู้เล่น และเลือกคะแนนเป้าหมาย TOEIC ของตัวเอง
- เลือกโหมดการฝึก 1 ใน 3 โหมด
- ตอบคำถามต้นฉบับสไตล์ TOEIC จำนวน 10 ข้อต่อรอบ ภายในเวลาข้อละ 15 วินาที
- รับคะแนน, EXP, เหรียญ, สตรีคโบนัส และเหรียญตรา **TOEIC Warrior**
- ดูกระดานผู้นำ Top 10 และคำแนะนำหมวดที่ควรพัฒนา

แอปนี้เหมาะสำหรับ **ผู้เริ่มต้น** ไปจนถึง **ผู้ที่อยากพิชิต 850+**
และเปิดโอกาสให้คุณเพิ่มคำถามของตัวเองในชีตได้ตามต้องการ

> หมายเหตุ: คำถามทั้งหมดในโปรเจกต์นี้เป็นคำถามต้นฉบับที่เขียนขึ้นใหม่
> ไม่ได้คัดลอกจากข้อสอบ TOEIC จริง เพื่อหลีกเลี่ยงปัญหาลิขสิทธิ์

## 2. ฟีเจอร์หลัก

### ฟีเจอร์ด้านผู้เล่น
- ระบบกรอกชื่อผู้เล่น (สูงสุด 30 ตัวอักษร)
- เลือกคะแนนเป้าหมาย: 500 / 650 / 750 / 850+
- เลือกโหมดการฝึก: Vocab / Grammar / Reading
- จับเวลาข้อละ 15 วินาที พร้อมแถบเวลาแบบลดลงเรียลไทม์
- แสดงคำตอบที่ถูก ผิด และคำอธิบายภาษาไทยทันทีหลังตอบ
- เคล็ดลับการเรียนภาษาไทยทุกข้อ
- หน้าสรุปผลแสดงคะแนน เลเวล EXP เหรียญ เหรียญตรา และจุดที่ควรพัฒนา
- กระดานผู้นำ Top 10 พร้อมเหรียญทอง เงิน ทองแดง

### ฟีเจอร์ด้านระบบ
- เชื่อมต่อ Google Sheets เป็นฐานข้อมูล (Questions, Scores, Mistakes, Settings)
- คำถาม 30 ข้อต้นฉบับเป็น seed data ให้พร้อมใช้งานทันที
- ระบบสุ่มคำถามไม่ซ้ำในรอบเดียว (Fisher-Yates shuffle)
- ใช้ `LockService` ป้องกันการเขียนชนกันเมื่อมีผู้เล่นพร้อมกัน
- ตรวจสอบและล้างค่าข้อมูลผู้ใช้ทั้งฝั่ง Client และ Server
- Mobile responsive ใช้งานได้ดีบนมือถือ
- รองรับ `prefers-reduced-motion` สำหรับผู้ใช้ที่อ่อนไหวต่อภาพเคลื่อนไหว

## 3. โหมดการฝึก

| โหมด | สไตล์ | ใกล้กับ TOEIC Part | ตัวอย่างเนื้อหา |
|---|---|---|---|
| 📚 **Vocab Rush** | คำศัพท์ธุรกิจ เติมคำในประโยค | Part 5 | คำกริยา/คำนามที่ใช้บ่อยในที่ทำงาน |
| 📝 **Grammar Sprint** | ไวยากรณ์ Part 5 | Part 5 | ประธาน-กริยา, tense, preposition, conditional |

### กฎการคิดคะแนน

- ตอบถูก: **+10 คะแนน**
- ตอบถูกภายใน 5 วินาที: **+5 คะแนนโบนัสความเร็ว**
- ตอบถูกติดต่อกันทุก 3 ข้อ: **+10 คะแนนโบนัสสตรีค**
- ตอบผิด/หมดเวลา: 0 คะแนน, สตรีครีเซ็ต
- จบ 1 รอบ: **+20 EXP**
- ตอบถูกแต่ละข้อ: **+5 เหรียญ**
- ทุก 100 EXP = ขึ้น 1 เลเวล
- ความแม่นยำ ≥ 80% รับเหรียญตรา **TOEIC Warrior**

> ค่าคะแนนทุกตัวสามารถปรับแต่งได้ในชีต `Settings` (ดูส่วนการติดตั้งในเฟสถัดไป)

## 5. โครงสร้างไฟล์

โปรเจกต์ประกอบด้วย 5 ไฟล์หลัก ทุกไฟล์อยู่ในโปรเจกต์ Google Apps Script เดียวกัน:

```
TOEIC Quest: Conquer 990/
├── Code.gs           (Backend หลัก – ฟังก์ชันทั้งหมดที่เซิร์ฟเวอร์ใช้)
├── Index.html        (โครง HTML ของแอปทั้งหมด 5 หน้าจอ)
├── Style.html        (CSS ทั้งหมด ธีม RPG + responsive)
├── Script.html       (JavaScript ฝั่ง Client ตัวควบคุมเกม)
└── README.md         (ไฟล์นี้)
```

### หน้าที่ของแต่ละไฟล์

#### `Code.gs`
รันบน Google Apps Script (V8) ทำหน้าที่:
- ให้บริการเว็บแอป (`doGet`)
- เชื่อมไฟล์ HTML ทั้งหมดผ่าน `include`
- สร้างชีตและ seed คำถาม 30 ข้อ (`setupSpreadsheet`)
- อ่าน/เขียนข้อมูลใน Google Sheets
- ตรวจสอบและล้างค่าข้อมูลผู้ใช้ (`sanitizeInput`)
- ส่งคำถามให้ Client (`getQuestions`)
- บันทึกคะแนน (`submitGameResult`) และข้อผิดพลาด (`saveMistakes`)
- ส่งกระดานผู้นำ (`getLeaderboard`)

#### `Index.html`
โครง DOM ทั้งหน้าจอ ประกอบด้วย:
- หน้าจอเริ่มต้น (Start)
- หน้าจอเลือกโหมด (Mode Selection)
- หน้าจอเล่นเกม (Game)
- หน้าจอสรุปผล (Result)
- หน้าจอกระดานผู้นำ (Leaderboard)
- Loading overlay และ Toast แจ้งสถานะ

#### `Style.html`
CSS ทั้งหมดของแอปในไฟล์เดียว
- ธีม Indigo + Violet + Gold สไตล์ RPG
- ใช้ Glass card + Backdrop blur
- มี animation เช่น เปลี่ยนหน้าจอ, สั่นเมื่อตอบผิด, เด้งเมื่อตอบถูก
- รองรับมือถือเล็ก ≤360px และแท็บเล็ต ≥720px

#### `Script.html`
ตัวควบคุมเกมทั้งหมดในฝั่ง Client (Vanilla JS)
- จัดการ State การเล่นรอบปัจจุบัน
- เรียก `google.script.run` เพื่อพูดคุยกับ Backend
- Render คำถาม, ตัวเลือก, ตัวจับเวลา, แถบความคืบหน้า
- คำนวณคะแนน, สตรีค, เหรียญ, EXP, เลเวล, เหรียญตรา
- จัดการเปลี่ยนหน้าจอและ feedback

#### `README.md`
ไฟล์นี้ คู่มือใช้งานและติดตั้ง (ภาษาไทย)

## 6. ภาพรวมระบบ

```
┌──────────────────────────────────────────────────────┐
│                   ผู้เล่น (เบราว์เซอร์)                  │
│  ┌────────────┐  ┌───────────┐  ┌────────────────┐   │
│  │ Index.html │  │ Style.html│  │  Script.html   │   │
│  │ (5 หน้าจอ) │  │   (CSS)   │  │ (ตัวคุม Game)  │    │
│  └─────┬──────┘  └───────────┘  └────────┬───────┘   │
│        │ template include                  │          │
│        │ <?!= include(...) ?>              │          │
└────────┼─────────────────────────────────────┼───────┘
         │            google.script.run        │
         ▼                                     ▼
┌──────────────────────────────────────────────────────┐
│              Google Apps Script (Server)             │
│                       Code.gs                        │
│   doGet · getQuestions · submitGameResult ·          │
│   saveMistakes · getLeaderboard · setupSpreadsheet   │
└─────────────────────────┬────────────────────────────┘
                          │ SpreadsheetApp + LockService
                          ▼
┌──────────────────────────────────────────────────────┐
│             Google Sheets (Database)                 │
│ ┌──────────┐ ┌────────┐ ┌──────────┐ ┌───────────┐   │
│ │Questions │ │Scores  │ │Mistakes  │ │Settings   │   │
│ │(คำถาม)   │ │(คะแนน) │ │(ข้อผิด)  │ │(ค่าตั้งค่า)│   │
│ └──────────┘ └────────┘ └──────────┘ └───────────┘   │
└──────────────────────────────────────────────────────┘
```

### ขั้นตอนการเล่น (Flow)

1. ผู้เล่นเปิดเว็บแอป → เห็นหน้าเริ่มต้น
2. กรอกชื่อ + เลือกคะแนนเป้าหมาย → กด **เริ่มผจญภัย**
3. เลือกโหมด 1 ใน 3 → ระบบโหลดคำถาม 10 ข้อแบบสุ่ม
4. ตอบทีละข้อในเวลา 15 วินาที → เห็นผลถูก/ผิด + คำอธิบายไทยทันที
5. ครบ 10 ข้อ → ระบบบันทึกคะแนนใน Google Sheets และแสดงสรุปผล
6. ผู้เล่นสามารถดูกระดานผู้นำ หรือเล่นรอบใหม่ได้ทันที

## 7. วิธีสร้าง Google Apps Script Project

ส่วนนี้แนะนำขั้นตอนสร้างโปรเจกต์ Google Apps Script ใหม่ และวางโค้ดของแอป
ลงในไฟล์ต่าง ๆ ให้ครบ คุณต้องมีบัญชี Google (Gmail) และเข้าถึง Google
Drive ได้เพียงเท่านั้น **ไม่ต้องติดตั้งโปรแกรมใด ๆ บนเครื่อง**

### ขั้นที่ 1 – สร้างโปรเจกต์ Google Apps Script ใหม่

1. เปิดเบราว์เซอร์แล้วเข้าหน้า [https://script.google.com](https://script.google.com)
2. ลงชื่อเข้าใช้บัญชี Google ของคุณ
3. คลิกปุ่ม **+ โปรเจกต์ใหม่** (New project) ที่มุมซ้ายบน
4. ระบบจะเปิดหน้าต่างแก้ไขโค้ด (Apps Script Editor) พร้อมไฟล์ตัวอย่างชื่อ
   `Code.gs` ที่มีฟังก์ชัน `myFunction()` เปล่า ๆ อยู่ก่อน

> 💡 หากเป็นครั้งแรก ระบบอาจถามให้ยอมรับเงื่อนไขการใช้งานบริการก่อน

### ขั้นที่ 2 – ตั้งชื่อโปรเจกต์

1. คลิกที่ข้อความ **โปรเจกต์ที่ไม่มีชื่อ** (Untitled project) ที่ด้านบนของหน้าต่าง
2. พิมพ์ชื่อโปรเจกต์: `TOEIC Quest: Conquer 990`
3. กด **Enter** หรือ **เปลี่ยนชื่อ** เพื่อยืนยัน

### ขั้นที่ 3 – แก้ไขไฟล์ Code.gs

1. ในหน้าต่าง Editor ด้านซ้ายมือ จะเห็นไฟล์ `Code.gs` อยู่แล้ว
2. คลิกที่ไฟล์ `Code.gs` เพื่อเปิด
3. **ลบโค้ดเดิมทั้งหมดในไฟล์** (กด `Ctrl + A` แล้ว `Delete`)
4. เปิดไฟล์ `Code.gs` จากโปรเจกต์นี้ → คัดลอกเนื้อหาทั้งหมด
5. กลับมาที่ Apps Script Editor → วางโค้ด (`Ctrl + V`) ลงในไฟล์ `Code.gs`
6. กดปุ่ม **บันทึก** (รูปดิสก์ 💾) ที่แถบเครื่องมือด้านบน หรือกด `Ctrl + S`

> ⚠️ ในไฟล์ `Code.gs` มีตัวแปร `SPREADSHEET_ID` ที่ยังเป็นค่าเริ่มต้น
> `'PUT_YOUR_SPREADSHEET_ID_HERE'` ขั้นนี้ยังไม่ต้องแก้ก็ได้
> เราจะมาตั้งค่าในเฟสถัดไปเมื่อสร้าง Google Sheets แล้ว

### ขั้นที่ 4 – สร้างไฟล์ Index.html

1. ในแถบไฟล์ด้านซ้าย คลิกปุ่ม **+** ข้างคำว่า **ไฟล์**
2. เลือก **HTML**
3. ตั้งชื่อไฟล์ว่า `Index` (ไม่ต้องใส่ `.html` ระบบจะเติมให้อัตโนมัติ)
4. กด **Enter** เพื่อสร้างไฟล์
5. ระบบจะเปิดไฟล์ `Index.html` ขึ้นมา และมีโค้ดตัวอย่างอยู่
6. **ลบเนื้อหาเดิมทั้งหมด**
7. คัดลอกเนื้อหาจากไฟล์ `Index.html` ของโปรเจกต์นี้ → วางลงไป
8. กด `Ctrl + S` เพื่อบันทึก

### ขั้นที่ 5 – สร้างไฟล์ Style.html

1. คลิกปุ่ม **+** → **HTML** อีกครั้ง
2. ตั้งชื่อไฟล์ว่า `Style`
3. กด **Enter**
4. ลบโค้ดตัวอย่างเดิม → วางเนื้อหาจากไฟล์ `Style.html` ของโปรเจกต์
5. กด `Ctrl + S` เพื่อบันทึก

### ขั้นที่ 6 – สร้างไฟล์ Script.html

1. คลิกปุ่ม **+** → **HTML**
2. ตั้งชื่อไฟล์ว่า `Script`
3. กด **Enter**
4. ลบโค้ดตัวอย่างเดิม → วางเนื้อหาจากไฟล์ `Script.html` ของโปรเจกต์
5. กด `Ctrl + S` เพื่อบันทึก

### ขั้นที่ 7 – ตรวจสอบโครงสร้างไฟล์ในโปรเจกต์

หลังเสร็จแล้ว แถบไฟล์ด้านซ้ายควรมี **4 ไฟล์** ดังนี้:

```
📁 TOEIC Quest: Conquer 990
├── 📄 Code.gs
├── 📄 Index.html
├── 📄 Style.html
└── 📄 Script.html
```

> ⚠️ ชื่อไฟล์ต้องสะกดให้ตรงกับด้านบน **โดยเฉพาะ "Index"** เพราะใน
> `Code.gs` มีบรรทัด `HtmlService.createTemplateFromFile('Index')`
> ที่อ้างถึงชื่อไฟล์นี้ตรง ๆ หากตั้งชื่ออื่น จะเปิดเว็บแอปไม่ได้

### ขั้นที่ 8 – บันทึกทั้งโปรเจกต์อีกครั้ง

1. กด `Ctrl + S` (หรือคลิกไอคอน 💾) เพื่อบันทึกไฟล์ทั้งหมด
2. ตรวจสอบว่าไม่มีจุดสีแดงค้างอยู่หน้าชื่อไฟล์ใด ๆ (จุดสีแดง = ยังไม่บันทึก)

### 📌 ข้อควรรู้เกี่ยวกับ Apps Script HTML Service

ก่อนไปขั้นตอนถัดไป ควรเข้าใจสิ่งเหล่านี้สั้น ๆ:

1. **ไฟล์ HTML ต้องลงท้าย `.html` เสมอ**
   - แม้จะใส่เฉพาะ CSS หรือ JavaScript ก็ตาม Apps Script รู้จักแค่ 2 ชนิด
     คือ `.gs` (สคริปต์) และ `.html` (แม่แบบ)
   - ดังนั้น CSS ของเราจึงอยู่ในไฟล์ `Style.html` ไม่ใช่ `Style.css`
   - และ JavaScript ฝั่ง Client ก็อยู่ใน `Script.html` ไม่ใช่ `Script.js`

2. **`<?!= include('Style'); ?>` คือ template scriptlet**
   - เป็นไวยากรณ์เฉพาะของ Apps Script HTML Service
   - ทำงานบนเซิร์ฟเวอร์ตอน render เพื่อแทรกเนื้อหาของไฟล์ที่ระบุเข้ามา
   - ฟังก์ชัน `include()` ถูกประกาศไว้ใน `Code.gs` เรียบร้อยแล้ว
   - ห้ามแก้ชื่อไฟล์ที่อ้างถึง เช่น `'Style'`, `'Script'` เพราะต้องตรงกับ
     ชื่อไฟล์ที่สร้างในโปรเจกต์

3. **`google.script.run` เป็นสะพานระหว่าง Frontend ↔ Backend**
   - ใช้เรียกฟังก์ชันใน `Code.gs` จากฝั่งเบราว์เซอร์
   - เรียกแบบ asynchronous เท่านั้น (ใช้ `withSuccessHandler` /
     `withFailureHandler` รับผลลัพธ์)
   - หากต้องดีบักจาก Console ของเบราว์เซอร์ จะเห็นเฉพาะข้อผิดพลาดของ
     ฝั่ง Client เท่านั้น ส่วนของ Server ดูได้ที่เมนู **บันทึกของผู้ดำเนินการ**
     (Executions) ในหน้า Apps Script

4. **เครื่องมือดีบักของ Apps Script**
   - ดู Log ที่ฝั่ง Server: เมนู **การบันทึก** (View → Logs) หรือกด `Ctrl + Enter`
   - ดูประวัติการทำงาน: เมนู **บันทึกของผู้ดำเนินการ** (Executions)
   - หากแก้ไขโค้ดแล้วเว็บแอปยังเป็นเวอร์ชันเก่า ให้ Deploy ใหม่ในเฟสถัดไป

5. **Apps Script ทำงานในบัญชีของคุณ**
   - เมื่อ Deploy เว็บแอป จะถามสิทธิ์เข้าถึง Google Sheets ครั้งแรก
   - ต้องกด **อนุญาต** เพื่อให้สคริปต์อ่าน/เขียนชีตของคุณได้
   - ไม่ส่งข้อมูลไปยังเซิร์ฟเวอร์ภายนอก ทุกอย่างอยู่ในบัญชี Google ของคุณ

## 8. วิธีสร้างและเชื่อมต่อ Google Sheets

ส่วนนี้จะสร้างฐานข้อมูล (Google Sheets) ให้กับเว็บแอป และเชื่อมต่อกับ
โปรเจกต์ Apps Script ที่เพิ่งสร้างไว้ในเฟสที่แล้ว

### ขั้นที่ 1 – สร้างไฟล์ Google Sheets ใหม่

1. เปิดเบราว์เซอร์แล้วเข้า [https://sheets.google.com](https://sheets.google.com)
2. คลิกปุ่ม **+ ว่าง** (Blank) เพื่อสร้างสเปรดชีตใหม่
3. คลิกที่ชื่อ **สเปรดชีตที่ไม่มีชื่อ** ด้านบนซ้าย → ตั้งชื่อใหม่ เช่น
   `TOEIC Quest Database`
4. กด **Enter** เพื่อยืนยัน
5. ไม่ต้องสร้างชีตย่อยเองหรือพิมพ์อะไรลงไป — สคริปต์จะสร้างให้อัตโนมัติ

### ขั้นที่ 2 – คัดลอก Spreadsheet ID

**Spreadsheet ID** คือสตริงยาวที่อยู่ใน URL ของไฟล์ Google Sheets
ตัวอย่าง URL ของชีต:

```
https://docs.google.com/spreadsheets/d/1aBcD2EfGhIjK3LmNoPqRsT4UvWxYzAbCdEfGhIjKlMn/edit#gid=0
                                       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                       นี่คือ Spreadsheet ID
```

ขั้นตอน:
1. ดูใน Address Bar ของเบราว์เซอร์
2. หาส่วนที่อยู่ระหว่าง `/d/` และ `/edit`
3. ลากเมาส์เลือกข้อความนั้น แล้วคัดลอก (`Ctrl + C`)

> 💡 ID ปกติจะมี **44 ตัวอักษร** ประกอบด้วยตัวอักษร ตัวเลข ขีดล่าง และขีดกลาง

### ขั้นที่ 3 – วาง Spreadsheet ID ลงใน Code.gs

1. กลับไปที่หน้าต่าง Apps Script Editor
2. เปิดไฟล์ `Code.gs`
3. ค้นหาบรรทัดนี้ (อยู่ราว ๆ บรรทัดที่ 28 ตอนต้นของไฟล์):

   ```javascript
   var SPREADSHEET_ID = 'PUT_YOUR_SPREADSHEET_ID_HERE';
   ```

4. แทนที่ `PUT_YOUR_SPREADSHEET_ID_HERE` ด้วย ID ที่คัดลอกมา ระวังเครื่องหมาย
   `'` (single quote) ครอบ ID ทั้งสองข้างต้องอยู่ครบ ตัวอย่างผลลัพธ์:

   ```javascript
   var SPREADSHEET_ID = '1aBcD2EfGhIjK3LmNoPqRsT4UvWxYzAbCdEfGhIjKlMn';
   ```

5. กด `Ctrl + S` เพื่อบันทึก

> ⚠️ ห้ามใส่ URL เต็มของ Google Sheets ลงไป ใส่เฉพาะ ID เท่านั้น
> มิฉะนั้นสคริปต์จะเปิดไฟล์ไม่ได้

### ขั้นที่ 4 – รันฟังก์ชัน setupSpreadsheet()

1. ที่ Apps Script Editor มองหาแถบเครื่องมือด้านบนของไฟล์ `Code.gs`
2. มีกล่องเลือกฟังก์ชันอยู่ตรงกลางแถบ ปกติจะแสดง `doGet`
3. คลิกที่กล่องนั้น แล้วเลือก **`setupSpreadsheet`**
4. คลิกปุ่ม **▶ เรียกใช้** (Run) ทางซ้ายของกล่องเลือกฟังก์ชัน

### ขั้นที่ 5 – ให้สิทธิ์การเข้าถึง (ครั้งแรกเท่านั้น)

ครั้งแรกที่รัน Apps Script จะถามสิทธิ์เพื่อเข้าถึง Google Sheets ของคุณ

1. หน้าต่างป๊อปอัปจะขึ้นมา **ต้องอนุมัติ**
2. คลิก **ตรวจสอบสิทธิ์** (Review permissions)
3. เลือกบัญชี Google ของคุณ
4. หากเห็นข้อความเตือนว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้:
   - คลิก **ขั้นสูง** (Advanced)
   - คลิก **ไปที่ TOEIC Quest: Conquer 990 (ไม่ปลอดภัย)**
   - นี่เป็นเรื่องปกติเพราะแอปยังไม่ได้รับการตรวจสอบจาก Google
   - แอปนี้เป็นโค้ดของคุณเอง จึงปลอดภัย
5. คลิก **อนุญาต** (Allow) เพื่อให้สคริปต์อ่าน/เขียนชีตของคุณได้
6. หน้าต่างจะปิด แล้วฟังก์ชัน `setupSpreadsheet` จะรันต่ออัตโนมัติ

### ขั้นที่ 6 – ตรวจสอบผลการทำงาน

หลังรันสำเร็จ:

1. ดูที่ **บันทึกการทำงาน** (Execution log) ด้านล่างของ Editor จะเห็นข้อความเช่น:

   ```
   setupSpreadsheet completed: {"spreadsheet":"TOEIC Quest Database",
     "created":["Questions","Scores","Mistakes","Settings"],
     "headersWritten":["Questions","Scores","Mistakes","Settings"],
     "settingsInserted":9,"questionsInserted":30}
   ```

2. กลับไปที่ไฟล์ Google Sheets ที่สร้างไว้ → กด **F5** หรือรีโหลดหน้า

3. ที่แถบล่างของชีต จะเห็น **4 แท็บ** ตามลำดับ:

   ```
   Questions | Scores | Mistakes | Settings
   ```

4. ตรวจสอบเนื้อหาแต่ละแท็บ:

   | แท็บ | สิ่งที่ควรเห็น |
   |---|---|
   | **Questions** | หัวคอลัมน์ 15 ช่อง + คำถาม 30 แถว (V001–V010, G001–G010, R001–R010) |
   | **Scores** | หัวคอลัมน์ 12 ช่อง (ยังไม่มีข้อมูล) |
   | **Mistakes** | หัวคอลัมน์ 8 ช่อง (ยังไม่มีข้อมูล) |
   | **Settings** | หัวคอลัมน์ 3 ช่อง + ค่าเริ่มต้น 9 แถว เช่น TimerSeconds=15 |

5. หากครบทั้งหมด แสดงว่าระบบฐานข้อมูลพร้อมใช้งานแล้ว 🎉

> 💡 **รันซ้ำได้ปลอดภัย**: หากรัน `setupSpreadsheet()` อีกครั้ง สคริปต์จะ
> ตรวจว่าชีตและข้อมูลมีอยู่แล้วหรือไม่ ถ้ามีจะข้ามไปโดยไม่เขียนทับ
> (idempotent) ดังนั้นคำถามที่คุณเพิ่มเองจะไม่หายไป

## 9. หน้าที่ของแต่ละชีต

### 📘 ชีต `Questions` — คลังคำถาม

ชีตหลักที่เก็บคำถามทั้งหมดของแอป มีคอลัมน์ดังนี้:

| คอลัมน์ | คำอธิบาย | ตัวอย่าง |
|---|---|---|
| Question_ID | รหัสคำถาม (ไม่ซ้ำกัน) | `V001`, `G003`, `R007` |
| Mode | โหมดของคำถาม | `Vocab Rush` / `Grammar Sprint` / `Reading Mission` |
| Part | หมวด TOEIC ที่อ้างอิง | `Part 5`, `Part 7` |
| Category | หัวข้อย่อย | `Business Meeting`, `Verb Tense` |
| Level | ระดับความยาก | `Easy`, `Medium`, `Hard` |
| Passage | บทอ่านสั้น (สำหรับ Reading เท่านั้น) | อีเมล/ประกาศ/รีวิว |
| Question_Text | โจทย์คำถาม | `The team will ______ the campaign...` |
| Choice_A | ตัวเลือก A | `discuss` |
| Choice_B | ตัวเลือก B | `disclose` |
| Choice_C | ตัวเลือก C | `dismiss` |
| Choice_D | ตัวเลือก D | `distract` |
| Correct_Answer | คำตอบที่ถูก (A/B/C/D) | `A` |
| Explanation_TH | คำอธิบายภาษาไทย | `คำว่า "discuss" แปลว่า...` |
| Tip | เคล็ดลับภาษาไทย | `จำว่า "discuss" ตามด้วยคำนามตรง...` |
| Point | คะแนนพื้นฐานของข้อนี้ | `10` |

> ✏️ คุณสามารถ **เพิ่ม / แก้ไข** คำถามในชีตนี้ได้ตลอดเวลา
> สคริปต์จะหยิบคำถามใหม่มาใช้ในรอบถัดไปอัตโนมัติ
> (ดูส่วน "วิธีเพิ่มคำถาม" ในเฟสถัดไป)

### 📗 ชีต `Scores` — บันทึกคะแนน

ชีตเก็บประวัติการเล่นทุกครั้ง (append-only — ระบบเขียนเพิ่มทีละแถวเท่านั้น)

| Timestamp | วันและเวลาที่เล่น |

| Wrong_Count | จำนวนข้อที่ตอบผิด/หมดเวลา |

| Badge | เหรียญตราที่ได้ (ถ้ามี เช่น `TOEIC Warrior`) |

> 📊 ใช้ชีตนี้สร้าง Pivot Table หรือกราฟแยกตามผู้เล่น/โหมดได้เลย

## 10. วิธี Deploy เป็น Web App

หลังจากสร้างโปรเจกต์และ Google Sheets เรียบร้อย ขั้นตอนสุดท้ายคือ
"Deploy" โปรเจกต์ Apps Script ให้กลายเป็นเว็บแอปที่เปิดผ่าน URL ได้

### ขั้นที่ 1 – เปิด Apps Script Editor ของโปรเจกต์

1. กลับไปที่ [https://script.google.com](https://script.google.com)
2. เปิดโปรเจกต์ **TOEIC Quest: Conquer 990** ที่สร้างไว้ในเฟส 7B
3. ตรวจสอบให้แน่ใจว่าไฟล์ `Code.gs`, `Index.html`, `Style.html`,
   `Script.html` ครบถ้วน และ `SPREADSHEET_ID` ถูกตั้งค่าแล้ว

### ขั้นที่ 2 – คลิกปุ่ม Deploy

1. มองหาปุ่มสีฟ้า **Deploy** (ใช้งาน) ที่มุมขวาบนของหน้าจอ
2. คลิกปุ่มนั้น เมนูจะดร็อปดาวน์ลงมา

### ขั้นที่ 3 – เลือก New deployment

1. ในเมนูดร็อปดาวน์ คลิก **New deployment** (การปรับใช้ใหม่)
2. หน้าต่างใหม่ "การปรับใช้ใหม่" จะเปิดขึ้นมา

### ขั้นที่ 4 – เลือกประเภทการ Deploy เป็น Web app

1. ที่ด้านซ้ายของหน้าต่าง จะมีไอคอนรูปฟันเฟือง ⚙ ข้างคำว่า
   **เลือกประเภท** (Select type)
2. คลิกฟันเฟืองนั้น
3. เลือก **เว็บแอป** (Web app)

> ⚠️ หากในรายการมีตัวเลือกอื่น เช่น `Add-on`, `API executable` อย่าเลือก
> ผิด ต้องเป็น **Web app** เท่านั้น

### ขั้นที่ 5 – กรอกคำอธิบาย (Description)

1. ในช่อง **คำอธิบาย** (Description) ใส่ข้อความที่จำได้ง่าย เช่น:

   ```
   TOEIC Quest v1.0 – initial release
   ```

2. คำอธิบายนี้ใช้สำหรับติดป้ายเวอร์ชันการ Deploy เท่านั้น
   ไม่กระทบการทำงานของแอป

### ขั้นที่ 6 – ตั้งค่า "Execute as" (ผู้ดำเนินการ)

ส่วนนี้กำหนดว่าสคริปต์จะรันด้วย **บัญชีของใคร**

1. ในช่อง **ดำเนินการในนามของ** (Execute as) เลือก **ฉัน (your-email@gmail.com)**
2. ความหมาย: ทุกครั้งที่มีคนเข้าเว็บแอป สคริปต์จะรันด้วยสิทธิ์ของ
   **บัญชีคุณ** ดังนั้นจะอ่าน/เขียน Google Sheets ของคุณได้แม้ผู้เข้าใช้
   จะไม่ได้รับสิทธิ์เข้าถึงชีตโดยตรง

> ⚠️ **สำคัญมาก**: ค่าเป็น "ฉัน" เท่านั้น ห้ามเลือก "ผู้ใช้ที่เข้าถึงเว็บแอป"
> เพราะทำให้สคริปต์อ่าน/เขียนชีตของผู้เข้าใช้แต่ละคน ซึ่งจะใช้กับโปรเจกต์นี้
> ไม่ได้ (เพราะชีตอยู่ในบัญชีคุณคนเดียว)

### ขั้นที่ 7 – ตั้งค่า "Who has access" (ผู้ที่เข้าถึงได้)

ส่วนนี้กำหนดว่า **ใครเปิดเว็บแอปนี้ได้บ้าง**

1. ในช่อง **ผู้ที่เข้าถึงได้** (Who has access) ให้เลือกตัวเลือกที่เหมาะกับ
   การใช้งานของคุณ:

| ตัวเลือก | เหมาะกับ | คำอธิบาย |
|---|---|---|
| **เฉพาะตัวฉัน** (Only myself) | ใช้คนเดียว | มีแต่บัญชีของคุณเท่านั้นที่เปิดได้ |
| **ใครก็ตามที่มีบัญชี Google** (Anyone with Google account) | ใช้ในกลุ่มเพื่อน | ผู้ที่มี Gmail ใด ๆ เปิดได้ ต้อง sign-in ก่อน |
| **ทุกคน** (Anyone) | เปิดสาธารณะ | ใครก็เปิดได้ ไม่ต้อง sign-in |

> 💡 หากบัญชีคุณเป็น Google Workspace (เช่น @company.com) จะมี
> ตัวเลือกเพิ่ม **"ทุกคนภายในองค์กร"** ซึ่งเหมาะสำหรับใช้ภายในบริษัท/โรงเรียน

### ขั้นที่ 8 – คลิกปุ่ม Deploy

1. ตรวจค่าทั้งหมดอีกครั้ง
2. คลิกปุ่ม **ปรับใช้** (Deploy) ที่มุมขวาล่างของหน้าต่าง

### ขั้นที่ 9 – อนุมัติสิทธิ์ (Authorize)

หากเป็นการ Deploy ครั้งแรก ระบบจะถามสิทธิ์อีกชุดหนึ่ง (สำหรับการรัน
ในฐานะ Web app)

1. คลิก **อนุมัติการเข้าถึง** (Authorize access)
2. เลือกบัญชี Google ของคุณ
3. หากเห็นข้อความ "Google ยังไม่ได้ยืนยันแอปนี้":
   - คลิก **ขั้นสูง** (Advanced)
   - คลิก **ไปที่ TOEIC Quest: Conquer 990 (ไม่ปลอดภัย)**
   - แอปนี้คือโค้ดของคุณเอง การเตือนนี้เป็นเรื่องปกติของ Apps Script
4. คลิก **อนุญาต** (Allow) เพื่อให้สิทธิ์
5. รอสักครู่จนหน้าต่าง Deploy แสดง URL

### ขั้นที่ 10 – คัดลอก Web App URL

1. หน้าต่าง "การปรับใช้อัปเดต" จะแสดงลิงก์ในช่อง **URL ของเว็บแอป**
2. URL จะเป็นรูปแบบ:

   ```
   https://script.google.com/macros/s/AKfycbx................/exec
   ```

3. คลิกปุ่ม **คัดลอก** (Copy) ข้าง URL หรือเลือกข้อความแล้ว `Ctrl + C`
4. **บันทึก URL นี้ไว้** เช่น แปะใน Note หรือบันทึกในมือถือ — เป็นที่อยู่
   ของเว็บแอปของคุณ
5. คลิก **เสร็จสิ้น** (Done) เพื่อปิดหน้าต่าง

### ขั้นที่ 11 – ทดสอบเว็บแอป

1. เปิดเบราว์เซอร์แท็บใหม่ (หรือเปิดบนมือถือเลยก็ได้)
2. วาง URL ที่คัดลอกไว้ในแถบที่อยู่ → กด Enter
3. รอสักครู่ — หน้าจอเริ่มต้นของเกมจะแสดงขึ้น พร้อมช่องกรอกชื่อและปุ่ม
   เลือกคะแนนเป้าหมาย
4. ทดลองกรอกชื่อ → เลือกคะแนน → กด **เริ่มผจญภัย**
5. เลือกโหมดใดก็ได้ → ตอบคำถามครบ 10 ข้อ
6. หลังจบรอบ ลองเปิดชีต `Scores` ใน Google Sheets — จะเห็นแถวใหม่ปรากฏ!

> 🎉 หากทำได้ตามขั้นตอนนี้ ถือว่า Deploy สำเร็จ และเว็บแอปพร้อมใช้งานเต็มรูปแบบ

### 🔧 คำแนะนำการตั้งค่าตามรูปแบบการใช้งาน

#### กรณีใช้งานส่วนตัว (ฝึกคนเดียว)

| ตั้งค่า | ค่า |

| Execute as | ฉัน |
| Who has access | เฉพาะตัวฉัน |
| ความปลอดภัย | สูงสุด ไม่มีคนอื่นเปิดได้ |

#### กรณีใช้ในองค์กร (เช่น โรงเรียน, บริษัท)

| ตั้งค่า | ค่า |
|---|---|
| Execute as | ฉัน |
| Who has access | ทุกคนภายในองค์กร (ต้องเป็น Google Workspace) |
| ความปลอดภัย | ใช้ได้เฉพาะคนในโดเมนเดียวกัน |

#### กรณีใช้สาธารณะ (เปิดให้ทุกคน)

| ตั้งค่า | ค่า |
|---|---|
| Execute as | ฉัน |
| Who has access | ทุกคน |
| ความปลอดภัย | ใครเปิดลิงก์ก็เล่นได้ ไม่ต้อง sign-in |

> ⚠️ **คำเตือนเรื่องโควต้า (Quota)**: Apps Script มีโควต้าการรันต่อวัน
> ในบัญชีฟรี (~6 ชั่วโมง CPU/วัน) หากแอปถูกใช้งานมากในเวลาเดียวกัน
> อาจขึ้น error `Service invoked too many times` ให้รอ 24 ชั่วโมง
> หรือเปลี่ยนไปใช้บัญชี Workspace ที่โควต้าสูงกว่า

> ⚠️ **คำเตือนเรื่องความเป็นส่วนตัว**: หากเปิดเป็น "ทุกคน" ใครก็เห็น
> กระดานผู้นำของคุณได้ ระวังอย่ากรอกข้อมูลส่วนตัวลงในชื่อผู้เล่น
> เช่น เบอร์โทร, อีเมล, รหัสนักศึกษา ฯลฯ

> ⚠️ **คำเตือนเรื่อง URL**: URL ของ Web App ทำหน้าที่เป็นกุญแจ — หากตั้งค่า
> "ทุกคน" ใครได้ลิงก์ก็เปิดได้ ไม่ควรโพสต์ URL ในที่สาธารณะหากต้องการ
> จำกัดผู้ใช้

## 11. วิธีใช้งานสำหรับผู้เล่น

ส่วนนี้คือคู่มือสำหรับ **ผู้เล่น** ที่เปิดเว็บแอปขึ้นมาเล่น
(ผู้ใช้ทั่วไป ไม่ใช่ผู้ติดตั้งระบบ) — แชร์ส่วนนี้ให้เพื่อนหรือนักเรียนได้เลย

### ขั้นที่ 1 – กรอกชื่อผู้เล่น

1. เปิดลิงก์เว็บแอปที่ได้รับมา (จะเป็น URL ลงท้ายด้วย `/exec`)
2. หน้าแรกที่เห็นคือ **หน้าจอเริ่มต้น** มีโลโก้ "TOEIC Quest"
3. ในช่อง **ชื่อผู้เล่น** พิมพ์ชื่อเล่นของคุณ (สูงสุด 30 ตัวอักษร)

> 💡 ใช้ชื่อที่จำได้ง่าย เพราะจะปรากฏในกระดานผู้นำ
> หลีกเลี่ยงข้อมูลส่วนตัว เช่น เบอร์โทร, อีเมล, รหัสนักศึกษา

### ขั้นที่ 2 – เลือกคะแนนเป้าหมาย TOEIC

1. ใต้ช่องชื่อ จะเห็นปุ่ม 4 ปุ่ม: **500 / 650 / 750 / 850+**
2. คลิกเลือกคะแนนเป้าหมายที่คุณต้องการพิชิต — ปุ่มที่เลือกจะเปลี่ยนสี

| ตัวเลือก | เหมาะกับ |
|---|---|
| **500** | ผู้เริ่มต้น เน้นพื้นฐานคำศัพท์ในที่ทำงาน |
| **650** | ระดับกลาง พอใช้ TOEIC สมัครงานทั่วไป |
| **750** | ระดับสูง สมัครงานบริษัทข้ามชาติ |
| **850+** | ระดับเชี่ยวชาญ พิชิตเต็ม 990 |

> 💡 คะแนนเป้าหมายไม่กระทบความยากของคำถามในเฟสนี้ แต่จะถูกบันทึกในชีต
> Scores ไว้ดูพัฒนาการของตัวเอง

### ขั้นที่ 3 – กดปุ่ม "เริ่มผจญภัย"

1. คลิกปุ่มสีม่วง **เริ่มผจญภัย**
2. หากกรอกชื่อหรือเลือกคะแนนเป้าหมายไม่ครบ จะมีข้อความสีแดงเตือน
3. หากครบ ระบบจะเข้าสู่หน้า **เลือกโหมดการฝึก**

> ⌨️ ผู้ใช้คีย์บอร์ด: กดปุ่ม **Enter** ในช่องชื่อก็เริ่มเกมได้ทันที

### ขั้นที่ 4 – เลือกโหมดการฝึก

1. หน้าจอจะแสดงการ์ด 3 ใบ:

| ไอคอน | โหมด | คำอธิบาย |
|---|---|---|
| 📚 | **Vocab Rush** | คำศัพท์ธุรกิจสไตล์ TOEIC แบบเร็ว ๆ |
| 📝 | **Grammar Sprint** | เติมคำในประโยค Part 5 |
| 📰 | **Reading Mission** | อ่านบทอ่านธุรกิจสั้น ๆ และตอบคำถาม |

2. คลิกการ์ดที่ต้องการเล่น
3. ระบบจะแสดง **Loading** สั้น ๆ พร้อมข้อความ "กำลังโหลดคำถาม..."
4. เมื่อโหลดเสร็จ จะเข้าสู่หน้าจอเล่นเกม

### ขั้นที่ 5 – ตอบคำถามก่อนหมดเวลา

หน้าจอเล่นเกมประกอบด้วย:

- **แถบข้อมูล (HUD)** ด้านบน: หมายเลขข้อปัจจุบัน / คะแนนรวม / สตรีค
- **แถบความคืบหน้า** สีทอง: บอกว่าทำไปแล้วกี่ข้อ
- **แถบเวลา**: ลดลงตามเวลา เปลี่ยนสี เขียว → เหลือง → แดง
- (ถ้าเป็น Reading Mission) **กล่องบทอ่าน**: อ่านก่อนตอบ
- **โจทย์คำถาม**
- **ปุ่มตัวเลือก A, B, C, D**

1. อ่านโจทย์ให้ละเอียด
2. คลิกตัวเลือกที่คิดว่าถูก ก่อนเวลาหมด (ค่าเริ่มต้น 15 วินาที)
3. หากเวลาหมดก่อนกด ระบบจะถือว่า "ตอบผิด" และแสดงคำตอบที่ถูก

> ⏰ ตอบถูกภายใน 5 วินาทีแรก จะได้ **โบนัสความเร็ว +5 คะแนน**

> 🔥 ตอบถูกติดต่อกันทุก 3 ข้อ จะได้ **โบนัสสตรีค +10 คะแนน**

### ขั้นที่ 6 – อ่านคำอธิบายและเคล็ดลับ

หลังกดตอบ (หรือหมดเวลา) ระบบจะ:

1. **ไฮไลต์ปุ่มสีเขียว** = คำตอบที่ถูกต้อง
2. **ไฮไลต์ปุ่มสีแดง** = คำตอบที่คุณกด (กรณีตอบผิด)
3. แสดงกล่อง **Feedback** ด้านล่างพร้อม:

   - หัวข้อ: ✓ ถูกต้อง / ✗ ไม่ถูกต้อง / ⏰ หมดเวลา
   - **คำอธิบาย** (Explanation) ภาษาไทยอย่างละเอียด
   - **เคล็ดลับ** (Tip) ภาษาไทยที่ช่วยจำ

> 📖 อ่านคำอธิบายให้ครบทุกข้อ — นี่คือจุดที่ทำให้คะแนน TOEIC คุณดีขึ้นจริง ๆ
> ไม่ใช่แค่ตอบให้ผ่าน

### ขั้นที่ 7 – ไปข้อต่อไป

1. หลังอ่านคำอธิบายเสร็จ คลิกปุ่มสีม่วง **ข้อต่อไป →**
2. ระบบจะโหลดคำถามถัดไป พร้อมรีเซ็ตเวลาเป็น 15 วินาทีอีกครั้ง
3. ทำซ้ำแบบนี้ครบ 10 ข้อ

> 🚪 หากต้องการออกกลางคัน คลิก **ออกจากเกม** (ลิงก์เล็ก ๆ ด้านล่าง)
> ระบบจะถามยืนยันก่อน — กดยืนยันแล้วจะกลับหน้าเริ่มต้น
> **คะแนนรอบนี้จะไม่ถูกบันทึก**

### ขั้นที่ 8 – ดูผลสรุป

หลังตอบครบ 10 ข้อ ระบบจะพาเข้าสู่ **หน้าจอสรุปผล** ซึ่งแสดง:

| รายการ | ความหมาย |
|---|---|
| **คะแนนรวม** | คะแนนทั้งหมดในรอบนี้ |
| **ความแม่นยำ** | เปอร์เซ็นต์ตอบถูก |
| **ตอบถูก / ตอบผิด** | จำนวนข้อ |
| **EXP** | แต้มประสบการณ์สะสม |
| **เหรียญ** | จำนวนเหรียญที่ได้ |
| **เลเวล** | เลเวลปัจจุบัน (ทุก 100 EXP = 1 เลเวล) |
| **เหรียญตรา** | "TOEIC Warrior" หากความแม่นยำ ≥ 80% |
| **จุดที่ควรพัฒนา** | หมวดที่ตอบผิดบ่อยที่สุด (ถ้ามี) |

ไอคอนด้านบนจะเปลี่ยนตามผลงาน:

- 🏆 ความแม่นยำ ≥ 80% (เก่งมาก!)
- 🎯 ความแม่นยำ 50–79% (พอใช้ได้)
- 💪 ความแม่นยำ < 50% (สู้ ๆ ฝึกต่อ!)

> ✅ ระบบจะ **บันทึกคะแนนอัตโนมัติ** ลง Google Sheets ขึ้นข้อความ
> "บันทึกคะแนนสำเร็จ" สั้น ๆ ที่ด้านล่างหน้าจอ

### ขั้นที่ 9 – ดูกระดานผู้นำ

1. ที่หน้าจอสรุปผล กดปุ่ม **ดูกระดานผู้นำ**
2. (หรือกดได้จากหน้าเริ่มต้น และจากปุ่มในแต่ละหน้าจอ)
3. ตารางจะแสดง **Top 10 ผู้เล่น** จัดอันดับตาม:
   1. คะแนนรวม (มากไปน้อย)
   2. ความแม่นยำ (กรณีคะแนนเท่ากัน)
   3. เวลาที่บันทึก (กรณีเสมอ ผู้บันทึกก่อนชนะ)
4. อันดับ 1–3 จะมีเหรียญทอง 🥇 เงิน 🥈 ทองแดง 🥉
5. แต่ละแถวแสดง:
   - อันดับ
   - ชื่อผู้เล่น + เลเวล + เหรียญตรา
   - โหมดที่เล่น
   - คะแนน
   - ความแม่นยำ (%)

> 🔄 กดไอคอน ⟳ ที่มุมขวาบนเพื่อ **รีเฟรช** ตารางหากเพิ่งเล่นเสร็จ

### ขั้นที่ 10 – เล่นอีกรอบ

มี 3 ทางเลือกสำหรับการเล่นต่อ:

| ปุ่ม | ผลลัพธ์ |
|---|---|
| **เล่นอีกรอบ** | กลับไปหน้าเลือกโหมด — ใช้ชื่อ/เป้าหมายเดิม |
| **กลับหน้าเริ่มต้น** | กลับไปกรอกชื่อใหม่ ตั้งเป้าหมายใหม่ |
| **ดูกระดานผู้นำ** | เช็คอันดับก่อนสู้ต่อ |

> 🎯 เล่นวันละ 1–2 รอบต่อโหมด สลับให้ครบทุกโหมด จะเห็นพัฒนาการ
> ในกระดานผู้นำชัดเจนภายใน 1 สัปดาห์

## 12. วิธีเพิ่มข้อสอบเองในชีต Questions

ข้อดีอย่างหนึ่งของการใช้ Google Sheets เป็นฐานข้อมูลคือ **คุณเพิ่มหรือ
แก้ไขคำถามได้ตลอดเวลาโดยไม่ต้องแตะโค้ดเลย** หลังบันทึกในชีต ระบบจะ
หยิบคำถามใหม่มาใช้ในรอบถัดไปอัตโนมัติ (ไม่ต้อง Deploy ใหม่)

### ขั้นตอนรวบยอด

1. เปิดไฟล์ Google Sheets ของคุณ → ไปที่แท็บ **Questions**
2. เลื่อนลงไปแถวว่างถัดจากคำถามสุดท้าย (เช่น แถวที่ 32 หากมี seed 30 ข้อ)
3. กรอกข้อมูลทั้ง 15 คอลัมน์ตามคำอธิบายด้านล่าง
4. กด `Ctrl + S` หรือออกจาก Cell — ระบบ Sheets บันทึกอัตโนมัติ
5. รีโหลดเว็บแอปแล้วเลือกโหมดเดิม จะมีโอกาสเจอคำถามใหม่

> ⚠️ **ห้ามลบหรือแก้ชื่อหัวคอลัมน์ในแถวที่ 1** เพราะระบบใช้ตำแหน่งและ
> ลำดับคอลัมน์ในการอ่านข้อมูล

---

### คำอธิบายทุกคอลัมน์

#### 1. Question_ID

- **ความหมาย**: รหัสประจำคำถามเอกลักษณ์ของแถวนั้น
- **ค่าที่ควรใช้**: เลือกเองได้ แต่ห้ามซ้ำกับแถวอื่น
- **คำแนะนำ**: ใช้คำนำหน้าเดียวกับโหมดเพื่อให้ดูง่าย เช่น
  - `V001`–`V010` สำหรับ Vocab Rush
  - `G001`–`G010` สำหรับ Grammar Sprint
  - `R001`–`R010` สำหรับ Reading Mission
  - คำถามใหม่ของคุณ: ต่อจากเลขสุดท้าย เช่น `V011`, `G011`, `R011`
- **ตัวอย่าง**: `V042`, `G028`, `R015`

#### 2. Mode

- **ความหมาย**: ระบุว่าคำถามนี้อยู่ในโหมดไหน
- **ค่าที่ใช้ได้**: ต้องสะกดให้ตรงทุกตัวอักษร (case-sensitive) — ใช้ค่า
  ใดค่าหนึ่งจาก:
  - `Vocab Rush`
  - `Grammar Sprint`
  - `Reading Mission`
- **ห้ามสะกดอื่น**: หากใส่ `vocab rush` (ตัวพิมพ์เล็ก) หรือ `Vocab` ฯลฯ
  ระบบจะกรองทิ้ง คำถามจะไม่ถูกใช้งาน

> 🔮 **โหมดในอนาคต**: หากในเฟสต่อไปคุณ (หรือผู้ดูแล) เพิ่มโหมดใหม่ เช่น
> `Mock Test Boss` (ข้อสอบจำลองทั้งชุด) หรือ `Listening Battle`
> (ฝึกฟัง) ก็สามารถใช้ค่าเหล่านี้ในคอลัมน์ Mode ได้ — แต่ต้องอัปเดต
> `ALLOWED_MODES` ใน `Code.gs` และเพิ่มการ์ดโหมดใน `Index.html` ก่อน
> จึงจะปรากฏในเว็บแอป

#### 3. Part

- **ความหมาย**: ระบุว่าคำถามนี้อ้างอิงสไตล์ TOEIC Part ใด
- **ค่าที่แนะนำ**: `Part 5`, `Part 6`, `Part 7`
- **ใช้ทำอะไร**: ปัจจุบันใช้แสดงเชิงอ้างอิงเท่านั้น ไม่กระทบการคัดเลือก
  คำถาม (อนาคตอาจกรองตาม Part ได้)

#### 4. Category

- **ความหมาย**: หัวข้อย่อยของคำถาม (จุดที่ฝึก)
- **ค่าที่แนะนำ**: เป็นภาษาอังกฤษ ตัวพิมพ์ใหญ่ขึ้นต้น เช่น
  - `Business Meeting`, `Finance`, `Logistics`, `Marketing`
  - `Subject-Verb Agreement`, `Verb Tense`, `Prepositions`, `Conditionals`
  - `Email`, `Notice`, `Memo`, `Job Posting`
- **สำคัญมาก**: ระบบใช้ค่า Category เพื่อคำนวณ **"จุดที่ควรพัฒนา"**
  ในหน้าสรุปผล ดังนั้นใช้ชื่อหมวดเดียวกันกับคำถามอื่นที่เกี่ยวข้อง
  (เช่น ใช้ `Verb Tense` ตลอด ไม่ผสม `Tense` กับ `Verb Tense`)

#### 5. Level

- **ความหมาย**: ระดับความยาก
- **ค่าที่แนะนำ**: `Easy`, `Medium`, `Hard`
- **ใช้ทำอะไร**: ปัจจุบันแสดงเชิงข้อมูลเท่านั้น (อนาคตอาจกรองตามระดับ)

#### 6. Passage

- **ความหมาย**: บทอ่าน (สำหรับโหมด Reading Mission)
- **ค่าที่ใช้**:
  - **Vocab Rush และ Grammar Sprint**: ปล่อยให้ว่าง (เซลล์เปล่า)
  - **Reading Mission**: ใส่บทอ่านสั้น ๆ 2–6 บรรทัด เช่น อีเมล,
    ประกาศ, โน้ต, รีวิวสินค้า
- **เคล็ดลับการขึ้นบรรทัดใหม่**: ใน Google Sheets ใช้ `Alt + Enter`
  (Windows) หรือ `Option + Enter` (Mac) เพื่อขึ้นบรรทัดใหม่ภายในเซลล์เดียว
- **ความยาวที่แนะนำ**: 50–200 คำ — สั้นพอให้อ่านในเวลาจำกัด

#### 7. Question_Text

- **ความหมาย**: ตัวคำถาม / โจทย์
- **รูปแบบ**:
  - **Vocab Rush และ Grammar Sprint**: ประโยคเติมคำใช้ `______`
    (ขีดล่าง 6 ตัวขึ้นไป) เพื่อแสดงช่องว่าง เช่น
    `The team will ______ the campaign at tomorrow's meeting.`
  - **Reading Mission**: คำถามจับใจความ เช่น
    `What is the main reason for the schedule change?`
- **ความยาว**: 1 บรรทัด ไม่ควรเกิน 200 ตัวอักษร

#### 8. Choice_A

- **ความหมาย**: ตัวเลือก A
- **รูปแบบ**: คำเดียวหรือวลีสั้น ๆ ตามบริบท
- **ตัวอย่าง**: `discuss`, `more detailed`, `By bringing the flyer to the café.`

#### 9. Choice_B

- **ความหมาย**: ตัวเลือก B (ตัวลวง / ตัวคำตอบ)
- **คำแนะนำ**: ตัวลวงควรใกล้เคียงคำตอบเพื่อให้ท้าทาย เช่น คำขึ้นต้น
  เดียวกัน (`disclose`) หรือรากศัพท์เดียวกัน (`detailed`)

#### 10. Choice_C

- **ความหมาย**: ตัวเลือก C
- **คำแนะนำ**: เช่นเดียวกับ Choice_B — สร้างตัวลวงที่ดี

#### 11. Choice_D

- **ความหมาย**: ตัวเลือก D
- **คำแนะนำ**: เช่นเดียวกับ Choice_B / Choice_C

> 💡 ข้อสอบ TOEIC จริงมักมี 4 ตัวเลือกเท่านั้น โปรเจกต์นี้ก็เช่นกัน
> ห้ามเว้นตัวเลือกใดให้ว่างเพราะระบบจะแสดงปุ่มที่ไม่มีข้อความ

#### 12. Correct_Answer

- **ความหมาย**: คำตอบที่ถูกต้อง
- **ค่าที่ใช้ได้**: ตัวอักษรตัวเดียวเท่านั้น `A`, `B`, `C`, หรือ `D`
- **ห้าม**: ใส่เป็น `a` (พิมพ์เล็ก), `1`, `Choice A`, หรือข้อความอื่น
- **ตัวอย่าง**: `A`

> ⚠️ ระบบจะ uppercase ค่านี้อัตโนมัติ ดังนั้นใส่ `a` ก็ใช้ได้
> แต่เพื่อความเรียบร้อย แนะนำให้ใส่ตัวพิมพ์ใหญ่ตลอด

#### 13. Explanation_TH

- **ความหมาย**: คำอธิบายภาษาไทยที่ผู้เล่นจะเห็นหลังตอบ
- **ค่าที่แนะนำ**: 1–3 ประโยค บอก
  - คำตอบที่ถูกแปลว่าอะไร
  - ทำไมถึงถูก (หลักการ / โครงสร้าง)
  - ทำไมตัวเลือกอื่นถึงไม่ใช่ (เพิ่มเติมเชิงอรรถ)
- **ตัวอย่าง**:
  ```
  คำว่า "discuss" แปลว่า "อภิปราย/พูดคุยเรื่อง" จึงเหมาะกับการประชุม
  ส่วน disclose = เปิดเผย, dismiss = ไล่ออก, distract = ทำให้เสียสมาธิ
  ```
- **คำเตือน**: หลีกเลี่ยงใช้เครื่องหมาย `<` หรือ `>` เพราะระบบจะกรองทิ้ง

#### 14. Tip

- **ความหมาย**: เคล็ดลับช่วยจำภาษาไทย
- **ค่าที่แนะนำ**: 1 ประโยคสั้น ๆ ที่จำง่าย เช่น
  - กฎไวยากรณ์ที่เกี่ยวข้อง
  - คู่คำ (collocation) ที่ออกข้อสอบบ่อย
  - เทคนิคการเดาคำตอบ
- **ตัวอย่าง**: `จำว่า "discuss" ตามด้วยคำนามตรง ๆ ได้เลย ไม่ต้องใส่ about`

#### 15. Point

- **ความหมาย**: คะแนนพื้นฐานสำหรับข้อนี้ (ก่อนรวมโบนัส)
- **ค่าที่แนะนำ**: `10` (เท่ากับ `BasePoint` ใน Settings)
- **อนาคต**: หากต้องการให้ข้อยากได้คะแนนมากกว่า อาจตั้ง `15` หรือ `20`
  สำหรับข้อ Hard เป็นพิเศษ (ต้องอัปเดตโค้ดเพิ่มเติมในอนาคตเพื่อใช้
  ค่านี้แทน BasePoint)

| 4 | Category | ✓ ใช้ชื่อสม่ำเสมอ | `Marketing` |
| 5 | Level | แนะนำ | `Medium` |
| 6 | Passage | เฉพาะ Reading | (ว่าง) |

> 💡 **เคล็ดลับการเพิ่มข้อสอบเร็ว ๆ**: ใช้ฟีเจอร์ "Copy down" ของ Google
> Sheets — เลือกแถวคำถามที่มีอยู่ → คัดลอก (`Ctrl + C`) → วางในแถวถัดไป
> (`Ctrl + V`) → เปลี่ยนเฉพาะข้อความที่ต้องเปลี่ยน จะประหยัดเวลามาก
