# 💧 Water KM Dashboard — ระบบสูบส่ง–สูบจ่ายน้ำ

Dashboard องค์ความรู้ (Knowledge Management) สรุปบทเรียนการเรียนรู้งาน
ระบบสูบส่งและสูบจ่ายน้ำ จัดทำเป็นเว็บ HTML ล้วน **เปิดใช้ได้ทันที ไม่ต้องติดตั้งอะไร**

> อ้างอิงเนื้อหาจากเอกสารสรุปบทเรียน *Commanding the Grid — An Operational Playbook*
> (สไลด์ 15 หน้า) + โครงข้อมูลจริงของหน่วยงานให้ทีมกรอกเพิ่ม

---

## วิธีใช้งาน

1. ดาวน์โหลด/clone โฟลเดอร์ `water-km-dashboard`
2. ดับเบิลคลิก `index.html` — เปิดใน Chrome/Edge ได้เลย
3. ใช้เมนูด้านบนกระโดดไปแต่ละหัวข้อ (12 หัวข้อ)

## การกรอก "ข้อมูลจริง" (หัวข้อ 10)

ข้อมูล TR/สถานีสูบจ่ายในไฟล์นี้เป็น **โครงเปล่า + ตัวอย่าง** (ติดป้ายสีเหลือง "ตัวอย่าง")
ต้องเติมค่าจริงจากหน้างานก่อนใช้อ้างอิง:

1. เปิดหัวข้อ 10 → กด **"✏️ โหมดแก้ไข"**
2. คลิกช่องสีเหลือง พิมพ์ชื่อสถานี / Flow / Pressure / รหัส RTU จริง
3. ข้อมูลบันทึกอัตโนมัติในเครื่อง (localStorage)
4. กด **"⬇️ ส่งออกข้อมูล (JSON)"** เพื่อแชร์ให้เพื่อนร่วมทีม
   — เพื่อนนำค่าไปวางแทนใน `js/data.js` ได้ เพื่อให้ทุกเครื่องเห็นเหมือนกัน

## การเพิ่มความรู้ใหม่ (Add-on)

หัวใจของโปรเจกต์นี้คือ **ข้อมูลแยกจากโค้ด** — ความรู้ทั้งหมดอยู่ใน `js/data.js`

- เพิ่มการ์ดความรู้: เพิ่ม object ใน `KM_DATA.addons`
  ```js
  { topic: "Pump Capacity สถานี A", body: "ปั๊ม 1: 2,500 ลบ.ม./ชม. …", by: "ชื่อผู้บันทึก", date: "2569-07-10" }
  ```
- เพิ่มคอลัมน์ข้อมูลสถานี: เพิ่ม field ใน `KM_DATA.network.stations`
  แล้วเพิ่มคู่ `["field", "หัวตาราง"]` ใน `SJ_COLS` (ไฟล์ `js/app.js`)
- ไม่ถนัดโค้ด? ใช้ Prompt สำเร็จรูปใน [`PROMPT.md`](PROMPT.md) สั่ง AI ทำให้ได้

```
water-km-dashboard/
├── index.html      ← หน้าหลัก (เปิดไฟล์นี้)

└── README.md       ← ไฟล์นี้
```

## หมายเหตุความถูกต้องของข้อมูล

- ป้าย **"จากเอกสาร"** = ตัวเลขจากสไลด์สรุปบทเรียนโดยตรง
- ป้าย **"ตัวอย่าง"** = ค่าสาธิต/รอยืนยัน — *ห้ามใช้อ้างอิงปฏิบัติการจริงจนกว่าจะเติมค่าจริง*
- ตัวเลขจำลองบางส่วน (เช่น ความสัมพันธ์ RPM→แรงดันในหัวข้อ 4) เป็นการประมาณเชิงสาธิต
  เพื่อการสอนเท่านั้น ไม่ใช่สมการวิศวกรรมจริง
