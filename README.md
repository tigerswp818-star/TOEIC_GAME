# TOEIC Quest: Conquer 990

เกมฝึก TOEIC สไตล์ RPG บน Google Apps Script + Google Sheets
ที่ช่วยให้ผู้เรียนฝึกคำศัพท์ ไวยากรณ์ และการอ่านภาษาอังกฤษเชิงธุรกิจ
ได้อย่างสนุก พร้อมระบบเก็บคะแนน เลเวล เหรียญ เหรียญตรา และกระดานผู้นำ

---

## 1. โปรเจกต์นี้คืออะไร

**TOEIC Quest: Conquer 990** คือเว็บแอปฝึก TOEIC ในรูปแบบเกม Quest
ผู้เล่นสามารถ:

- กรอกชื่อผู้เล่น และเลือกคะแนนเป้าหมาย TOEIC ของตัวเอง
- เลือกโหมดการฝึก 1 ใน 3 โหมด
- ตอบคำถามต้นฉบับสไตล์ TOEIC จำนวน 10 ข้อต่อรอบ ภายในเวลาข้อละ 15 วินาที
- รับคะแนน, EXP, เหรียญ, สตรีคโบนัส และเหรียญตรา **TOEIC Warrior**
- ดูกระดานผู้นำ Top 10 และคำแนะนำหมวดที่ควรพัฒนา

แอปนี้เหมาะสำหรับ **ผู้เริ่มต้น** ไปจนถึง **ผู้ที่อยากพิชิต 850+**
และเปิดโอกาสให้คุณเพิ่มคำถามของตัวเองในชีตได้ตามต้องการ

> หมายเหตุ: คำถามทั้งหมดในโปรเจกต์นี้เป็นคำถามต้นฉบับที่เขียนขึ้นใหม่
> ไม่ได้คัดลอกจากข้อสอบ TOEIC จริง เพื่อหลีกเลี่ยงปัญหาลิขสิทธิ์

## 2. ฟีเจอร์หลัก

### ฟีเจอร์ด้านผู้เล่น
- ระบบกรอกชื่อผู้เล่น (สูงสุด 30 ตัวอักษร)
- เลือกคะแนนเป้าหมาย: 500 / 650 / 750 / 850+
- เลือกโหมดการฝึก: Vocab / Grammar / Reading
- จับเวลาข้อละ 15 วินาที พร้อมแถบเวลาแบบลดลงเรียลไทม์
- แสดงคำตอบที่ถูก ผิด และคำอธิบายภาษาไทยทันทีหลังตอบ
- เคล็ดลับการเรียนภาษาไทยทุกข้อ
- หน้าสรุปผลแสดงคะแนน เลเวล EXP เหรียญ เหรียญตรา และจุดที่ควรพัฒนา
- กระดานผู้นำ Top 10 พร้อมเหรียญทอง เงิน ทองแดง

### ฟีเจอร์ด้านระบบ
- เชื่อมต่อ Google Sheets เป็นฐานข้อมูล (Questions, Scores, Mistakes, Settings)
- คำถาม 30 ข้อต้นฉบับเป็น seed data ให้พร้อมใช้งานทันที
- ระบบสุ่มคำถามไม่ซ้ำในรอบเดียว (Fisher-Yates shuffle)
- ใช้ `LockService` ป้องกันการเขียนชนกันเมื่อมีผู้เล่นพร้อมกัน
- ตรวจสอบและล้างค่าข้อมูลผู้ใช้ทั้งฝั่ง Client และ Server
- Mobile responsive ใช้งานได้ดีบนมือถือ
- รองรับ `prefers-reduced-motion` สำหรับผู้ใช้ที่อ่อนไหวต่อภาพเคลื่อนไหว

## 3. โหมดการฝึก

| โหมด | สไตล์ | ใกล้กับ TOEIC Part | ตัวอย่างเนื้อหา |
|---|---|---|---|
| 📚 **Vocab Rush** | คำศัพท์ธุรกิจ เติมคำในประโยค | Part 5 | คำกริยา/คำนามที่ใช้บ่อยในที่ทำงาน |
| 📝 **Grammar Sprint** | ไวยากรณ์ Part 5 | Part 5 | ประธาน-กริยา, tense, preposition, conditional |
| 📰 **Reading Mission** | อ่านบทความธุรกิจสั้น ๆ | Part 7 | อีเมล, โน้ต, ประกาศ, รีวิวสินค้า |

### กฎการคิดคะแนน

- ตอบถูก: **+10 คะแนน**
- ตอบถูกภายใน 5 วินาที: **+5 คะแนนโบนัสความเร็ว**
- ตอบถูกติดต่อกันทุก 3 ข้อ: **+10 คะแนนโบนัสสตรีค**
- ตอบผิด/หมดเวลา: 0 คะแนน, สตรีครีเซ็ต
- จบ 1 รอบ: **+20 EXP**
- ตอบถูกแต่ละข้อ: **+5 เหรียญ**
- ทุก 100 EXP = ขึ้น 1 เลเวล
- ความแม่นยำ ≥ 80% รับเหรียญตรา **TOEIC Warrior**

> ค่าคะแนนทุกตัวสามารถปรับแต่งได้ในชีต `Settings` (ดูส่วนการติดตั้งในเฟสถัดไป)

## 5. โครงสร้างไฟล์

โปรเจกต์ประกอบด้วย 5 ไฟล์หลัก ทุกไฟล์อยู่ในโปรเจกต์ Google Apps Script เดียวกัน:

```
TOEIC Quest: Conquer 990/
├── Code.gs           (Backend หลัก – ฟังก์ชันทั้งหมดที่เซิร์ฟเวอร์ใช้)
├── Index.html        (โครง HTML ของแอปทั้งหมด 5 หน้าจอ)
├── Style.html        (CSS ทั้งหมด ธีม RPG + responsive)
├── Script.html       (JavaScript ฝั่ง Client ตัวควบคุมเกม)
└── README.md         (ไฟล์นี้)
```

### หน้าที่ของแต่ละไฟล์

#### `Code.gs`
รันบน Google Apps Script (V8) ทำหน้าที่:
- ให้บริการเว็บแอป (`doGet`)
- เชื่อมไฟล์ HTML ทั้งหมดผ่าน `include`
- สร้างชีตและ seed คำถาม 30 ข้อ (`setupSpreadsheet`)
- อ่าน/เขียนข้อมูลใน Google Sheets
- ตรวจสอบและล้างค่าข้อมูลผู้ใช้ (`sanitizeInput`)
- ส่งคำถามให้ Client (`getQuestions`)
- บันทึกคะแนน (`submitGameResult`) และข้อผิดพลาด (`saveMistakes`)
- ส่งกระดานผู้นำ (`getLeaderboard`)

#### `Index.html`
โครง DOM ทั้งหน้าจอ ประกอบด้วย:
- หน้าจอเริ่มต้น (Start)
- หน้าจอเลือกโหมด (Mode Selection)
- หน้าจอเล่นเกม (Game)
- หน้าจอสรุปผล (Result)
- หน้าจอกระดานผู้นำ (Leaderboard)
- Loading overlay และ Toast แจ้งสถานะ

#### `Style.html`
CSS ทั้งหมดของแอปในไฟล์เดียว
- ธีม Indigo + Violet + Gold สไตล์ RPG
- ใช้ Glass card + Backdrop blur
- มี animation เช่น เปลี่ยนหน้าจอ, สั่นเมื่อตอบผิด, เด้งเมื่อตอบถูก
- รองรับมือถือเล็ก ≤360px และแท็บเล็ต ≥720px

#### `Script.html`
ตัวควบคุมเกมทั้งหมดในฝั่ง Client (Vanilla JS)
- จัดการ State การเล่นรอบปัจจุบัน
- เรียก `google.script.run` เพื่อพูดคุยกับ Backend
- Render คำถาม, ตัวเลือก, ตัวจับเวลา, แถบความคืบหน้า
- คำนวณคะแนน, สตรีค, เหรียญ, EXP, เลเวล, เหรียญตรา
- จัดการเปลี่ยนหน้าจอและ feedback

#### `README.md`
ไฟล์นี้ คู่มือใช้งานและติดตั้ง (ภาษาไทย)

## 6. ภาพรวมระบบ

```
┌──────────────────────────────────────────────────────┐
│                   ผู้เล่น (เบราว์เซอร์)                  │
│  ┌────────────┐  ┌───────────┐  ┌────────────────┐   │
│  │ Index.html │  │ Style.html│  │  Script.html   │   │
│  │ (5 หน้าจอ) │  │   (CSS)   │  │ (ตัวคุม Game)  │    │
│  └─────┬──────┘  └───────────┘  └────────┬───────┘   │
│        │ template include                  │          │
│        │ <?!= include(...) ?>              │          │
└────────┼─────────────────────────────────────┼───────┘
         │            google.script.run        │
         ▼                                     ▼
┌──────────────────────────────────────────────────────┐
│              Google Apps Script (Server)             │
│                       Code.gs                        │
│   doGet · getQuestions · submitGameResult ·          │
│   saveMistakes · getLeaderboard · setupSpreadsheet   │
└─────────────────────────┬────────────────────────────┘
                          │ SpreadsheetApp + LockService
                          ▼
┌──────────────────────────────────────────────────────┐
│             Google Sheets (Database)                 │
│ ┌──────────┐ ┌────────┐ ┌──────────┐ ┌───────────┐   │
│ │Questions │ │Scores  │ │Mistakes  │ │Settings   │   │
│ │(คำถาม)   │ │(คะแนน) │ │(ข้อผิด)  │ │(ค่าตั้งค่า)│   │
│ └──────────┘ └────────┘ └──────────┘ └───────────┘   │
└──────────────────────────────────────────────────────┘
```

### ขั้นตอนการเล่น (Flow)

1. ผู้เล่นเปิดเว็บแอป → เห็นหน้าเริ่มต้น
2. กรอกชื่อ + เลือกคะแนนเป้าหมาย → กด **เริ่มผจญภัย**
3. เลือกโหมด 1 ใน 3 → ระบบโหลดคำถาม 10 ข้อแบบสุ่ม
4. ตอบทีละข้อในเวลา 15 วินาที → เห็นผลถูก/ผิด + คำอธิบายไทยทันที
5. ครบ 10 ข้อ → ระบบบันทึกคะแนนใน Google Sheets และแสดงสรุปผล
6. ผู้เล่นสามารถดูกระดานผู้นำ หรือเล่นรอบใหม่ได้ทันที

## 7. วิธีสร้าง Google Apps Script Project

ส่วนนี้แนะนำขั้นตอนสร้างโปรเจกต์ Google Apps Script ใหม่ และวางโค้ดของแอป
ลงในไฟล์ต่าง ๆ ให้ครบ คุณต้องมีบัญชี Google (Gmail) และเข้าถึง Google
Drive ได้เพียงเท่านั้น **ไม่ต้องติดตั้งโปรแกรมใด ๆ บนเครื่อง**

### ขั้นที่ 1 – สร้างโปรเจกต์ Google Apps Script ใหม่

1. เปิดเบราว์เซอร์แล้วเข้าหน้า [https://script.google.com](https://script.google.com)
2. ลงชื่อเข้าใช้บัญชี Google ของคุณ
3. คลิกปุ่ม **+ โปรเจกต์ใหม่** (New project) ที่มุมซ้ายบน
4. ระบบจะเปิดหน้าต่างแก้ไขโค้ด (Apps Script Editor) พร้อมไฟล์ตัวอย่างชื่อ
   `Code.gs` ที่มีฟังก์ชัน `myFunction()` เปล่า ๆ อยู่ก่อน

> 💡 หากเป็นครั้งแรก ระบบอาจถามให้ยอมรับเงื่อนไขการใช้งานบริการก่อน

### ขั้นที่ 2 – ตั้งชื่อโปรเจกต์

1. คลิกที่ข้อความ **โปรเจกต์ที่ไม่มีชื่อ** (Untitled project) ที่ด้านบนของหน้าต่าง
2. พิมพ์ชื่อโปรเจกต์: `TOEIC Quest: Conquer 990`
3. กด **Enter** หรือ **เปลี่ยนชื่อ** เพื่อยืนยัน

### ขั้นที่ 3 – แก้ไขไฟล์ Code.gs

1. ในหน้าต่าง Editor ด้านซ้ายมือ จะเห็นไฟล์ `Code.gs` อยู่แล้ว
2. คลิกที่ไฟล์ `Code.gs` เพื่อเปิด
3. **ลบโค้ดเดิมทั้งหมดในไฟล์** (กด `Ctrl + A` แล้ว `Delete`)
4. เปิดไฟล์ `Code.gs` จากโปรเจกต์นี้ → คัดลอกเนื้อหาทั้งหมด
5. กลับมาที่ Apps Script Editor → วางโค้ด (`Ctrl + V`) ลงในไฟล์ `Code.gs`
6. กดปุ่ม **บันทึก** (รูปดิสก์ 💾) ที่แถบเครื่องมือด้านบน หรือกด `Ctrl + S`

> ⚠️ ในไฟล์ `Code.gs` มีตัวแปร `SPREADSHEET_ID` ที่ยังเป็นค่าเริ่มต้น
> `'PUT_YOUR_SPREADSHEET_ID_HERE'` ขั้นนี้ยังไม่ต้องแก้ก็ได้
> เราจะมาตั้งค่าในเฟสถัดไปเมื่อสร้าง Google Sheets แล้ว

### ขั้นที่ 4 – สร้างไฟล์ Index.html

1. ในแถบไฟล์ด้านซ้าย คลิกปุ่ม **+** ข้างคำว่า **ไฟล์**
2. เลือก **HTML**
3. ตั้งชื่อไฟล์ว่า `Index` (ไม่ต้องใส่ `.html` ระบบจะเติมให้อัตโนมัติ)
4. กด **Enter** เพื่อสร้างไฟล์
5. ระบบจะเปิดไฟล์ `Index.html` ขึ้นมา และมีโค้ดตัวอย่างอยู่
6. **ลบเนื้อหาเดิมทั้งหมด**
7. คัดลอกเนื้อหาจากไฟล์ `Index.html` ของโปรเจกต์นี้ → วางลงไป
8. กด `Ctrl + S` เพื่อบันทึก

### ขั้นที่ 5 – สร้างไฟล์ Style.html

1. คลิกปุ่ม **+** → **HTML** อีกครั้ง
2. ตั้งชื่อไฟล์ว่า `Style`
3. กด **Enter**
4. ลบโค้ดตัวอย่างเดิม → วางเนื้อหาจากไฟล์ `Style.html` ของโปรเจกต์
5. กด `Ctrl + S` เพื่อบันทึก

### ขั้นที่ 6 – สร้างไฟล์ Script.html

1. คลิกปุ่ม **+** → **HTML**
2. ตั้งชื่อไฟล์ว่า `Script`
3. กด **Enter**
4. ลบโค้ดตัวอย่างเดิม → วางเนื้อหาจากไฟล์ `Script.html` ของโปรเจกต์
5. กด `Ctrl + S` เพื่อบันทึก

### ขั้นที่ 7 – ตรวจสอบโครงสร้างไฟล์ในโปรเจกต์

หลังเสร็จแล้ว แถบไฟล์ด้านซ้ายควรมี **4 ไฟล์** ดังนี้:

```
📁 TOEIC Quest: Conquer 990
├── 📄 Code.gs
├── 📄 Index.html
├── 📄 Style.html
└── 📄 Script.html
```

> ⚠️ ชื่อไฟล์ต้องสะกดให้ตรงกับด้านบน **โดยเฉพาะ "Index"** เพราะใน
> `Code.gs` มีบรรทัด `HtmlService.createTemplateFromFile('Index')`
> ที่อ้างถึงชื่อไฟล์นี้ตรง ๆ หากตั้งชื่ออื่น จะเปิดเว็บแอปไม่ได้

### ขั้นที่ 8 – บันทึกทั้งโปรเจกต์อีกครั้ง

1. กด `Ctrl + S` (หรือคลิกไอคอน 💾) เพื่อบันทึกไฟล์ทั้งหมด
2. ตรวจสอบว่าไม่มีจุดสีแดงค้างอยู่หน้าชื่อไฟล์ใด ๆ (จุดสีแดง = ยังไม่บันทึก)

### 📌 ข้อควรรู้เกี่ยวกับ Apps Script HTML Service

ก่อนไปขั้นตอนถัดไป ควรเข้าใจสิ่งเหล่านี้สั้น ๆ:

1. **ไฟล์ HTML ต้องลงท้าย `.html` เสมอ**
   - แม้จะใส่เฉพาะ CSS หรือ JavaScript ก็ตาม Apps Script รู้จักแค่ 2 ชนิด
     คือ `.gs` (สคริปต์) และ `.html` (แม่แบบ)
   - ดังนั้น CSS ของเราจึงอยู่ในไฟล์ `Style.html` ไม่ใช่ `Style.css`
   - และ JavaScript ฝั่ง Client ก็อยู่ใน `Script.html` ไม่ใช่ `Script.js`

2. **`<?!= include('Style'); ?>` คือ template scriptlet**
   - เป็นไวยากรณ์เฉพาะของ Apps Script HTML Service
   - ทำงานบนเซิร์ฟเวอร์ตอน render เพื่อแทรกเนื้อหาของไฟล์ที่ระบุเข้ามา
   - ฟังก์ชัน `include()` ถูกประกาศไว้ใน `Code.gs` เรียบร้อยแล้ว
   - ห้ามแก้ชื่อไฟล์ที่อ้างถึง เช่น `'Style'`, `'Script'` เพราะต้องตรงกับ
     ชื่อไฟล์ที่สร้างในโปรเจกต์

3. **`google.script.run` เป็นสะพานระหว่าง Frontend ↔ Backend**
   - ใช้เรียกฟังก์ชันใน `Code.gs` จากฝั่งเบราว์เซอร์
   - เรียกแบบ asynchronous เท่านั้น (ใช้ `withSuccessHandler` /
     `withFailureHandler` รับผลลัพธ์)
   - หากต้องดีบักจาก Console ของเบราว์เซอร์ จะเห็นเฉพาะข้อผิดพลาดของ
     ฝั่ง Client เท่านั้น ส่วนของ Server ดูได้ที่เมนู **บันทึกของผู้ดำเนินการ**
     (Executions) ในหน้า Apps Script

4. **เครื่องมือดีบักของ Apps Script**
   - ดู Log ที่ฝั่ง Server: เมนู **การบันทึก** (View → Logs) หรือกด `Ctrl + Enter`
   - ดูประวัติการทำงาน: เมนู **บันทึกของผู้ดำเนินการ** (Executions)
   - หากแก้ไขโค้ดแล้วเว็บแอปยังเป็นเวอร์ชันเก่า ให้ Deploy ใหม่ในเฟสถัดไป

5. **Apps Script ทำงานในบัญชีของคุณ**
   - เมื่อ Deploy เว็บแอป จะถามสิทธิ์เข้าถึง Google Sheets ครั้งแรก
   - ต้องกด **อนุญาต** เพื่อให้สคริปต์อ่าน/เขียนชีตของคุณได้
   - ไม่ส่งข้อมูลไปยังเซิร์ฟเวอร์ภายนอก ทุกอย่างอยู่ในบัญชี Google ของคุณ
